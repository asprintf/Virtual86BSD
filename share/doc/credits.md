# Credits: code adapted from the BSDs

V86BSD is a fork of Shall; part of its BSD side is code that was *adapted*
from OpenBSD and NetBSD, not written here. Each such file keeps the
original copyright and licence text word for word and has, after it, a
note `Adapted for V86BSD from OpenBSD|NetBSD <path> (revision N). Changes:
...` that names the source file, its revision and what was changed. This
table is made from those notes (`grep -rl "Adapted for V86BSD from"`);
the note in the file is the authority.

Sources were chosen by their licences: every file below carries the
BSD licence of the Regents of the University of California or a
similar one (three or two clauses), or, for one file, the ISC licence;
the terminal database `share/terminfo/terminfo` is ncurses' (MIT-style,
as its header explains), and `lib/libcurses/shlib_version` holds only
two version numbers. **None has an advertising clause**, and none is
under the GPL. Checked on 2026-11-13 by reading the licence text of each
file. What was left out for its licence: NetBSD's `makefs` front end
(`makefs.c`, `walk.c`, `ffs.c` and their headers: four clauses, Wasabi
Systems), NetBSD's `lib/libcurses/instr.c` and `inchstr.c` (four clauses,
Wasabi Systems), OpenBSD's `ffs_softdep.c` (a special licence), and
Linux's `ufs` and e2fsprogs (GPL). `makefs`'s front end, tree reader,
image builder and buffers, and libcurses' `instr.c` and `inchstr.c`, were
written for V86BSD instead.

libcurses (`lib/libcurses`, X/Open Curses with NetBSD's libterminfo in
`terminfo/` and its cdb reader and writer in `cdb/`) has, besides the
files below, V86BSD's own: `instr.c`, `inchstr.c`, `vidattr.c`,
`scr_dump.c`, `terminfo/termcap_hash.c` (NetBSD makes those tables with
`nbperf`, which V86BSD does not have), `compat/` (what the NetBSD sources
expect of NetBSD's headers), the `Makefile`, and
`terminfo/compiled_terms.c`, generated by `tic` from
`share/terminfo/terminfo` (`make terms`).

Not in the table: code written here that only follows a BSD's interface
or behaviour (`err(3)`, `getprogname(3)`, `arc4random(3)`, `syslogd`,
`ifconfig`, `route`, ...: compared with the BSDs' manual pages, not copied)
and the Shall code the fork started from (see `LICENSE`).
